# feat: 사용 가이드 라벨 + 힌트 단계 설명 보강

## 요약

만들기/수정 폼의 사용 가이드 진입점과 힌트 설명 두 가지를 개선.

1. **`?` 버튼 → `사용 가이드` 텍스트 버튼**으로 교체. 처음 보는 선생님도
   이 버튼이 무엇인지 한눈에 알 수 있도록.
2. **힌트 단계 안내를 4가지 타입별 예시 형태로 확장**. 한 문단에 모든
   설명을 욱여넣지 않고, 정답이 「치킨」일 때 각 타입이 어떻게 보이는지
   글머리표로 펼침.

## 변경 사항

### 1. 가이드 진입점 라벨 변경 (`QuizForm.tsx`)

이전:
```tsx
<button ... aria-label="가이드 보기">?</button>
```

이후:
```tsx
<button ...>사용 가이드</button>
```

- 동그란 아이콘 버튼(8x8)을 일반 텍스트 버튼으로 변경.
- `aria-label` 제거 — 보이는 라벨이 곧 의미를 전달하므로 중복 안내가
  필요 없음.

### 2. 힌트 단계 콘텐츠 확장 (`TOUR_STEPS` `add-hint` 단계)

이전: 한 문단으로 4종류 힌트를 나열.

이후: JSX 노드로 교체해서 글머리표 + 굵은 라벨 + 「인용」 예시 형태로
정리. 정답 「치킨」을 공통 예시로 사용.

- **텍스트** — 직접 쓴 문장 힌트. 예: 「닭으로 만든 음식」
- **받침** — 그 글자의 받침만 공개. 예: 「친」의 받침 「ㄴ」
- **모음** — 자음+모음만 공개, 받침은 가림. 예: 「치」, 「키」
- **글자 전체** — 그 글자 통째로 공개. 예: 「치」

마지막 문단에서 chip 다중 선택과 풀기 화면의 셀 단위 공개 규칙도 그대로
유지.

## 핵심 설계 결정

### react-joyride `content`에 JSX 사용

`Step['content']`는 `string | ReactNode` 둘 다 받음. 글머리표 + 굵은
라벨로 시각 위계를 주고 싶었기에 JSX 노드로 작성.

### 한국어 인용부호 「」 사용

JSX text 안의 큰따옴표는 ESLint의 `react/no-unescaped-entities`에
걸림. `&quot;` 또는 `{'"..."'}`로 escape할 수 있지만, 한국어 컨텍스트엔
「」가 더 자연스럽고 escape도 불필요해 한 번에 두 가지를 해결.

### 가이드 버튼 위치는 그대로

CLAUDE.md 원래 스펙은 모든 페이지에 가이드 버튼을 두는 것이지만, 이번
PR은 "라벨 + 힌트 설명" 개선에만 집중. 다른 페이지로의 확장은 별도
PR에서 다룰 예정.
